# Loupi Garoupi Tem Vontade de Partir — letra (cânone)

> Caô · *Contas Para Um Colar (Primeiro Ato)* · lançada em 16/01/2026.
> Texto colado pelo Carlos em 29/09/2026 (vídeo: https://www.youtube.com/watch?v=DxYU-Lc0Ous). É a letra publicada, **não** rascunho: serve de cânone para o EP *Sozinho em Procissão*.
> O nome "Loupi" não aparece no texto cantado, só no título. Não há problema de pronúncia nesta faixa.
